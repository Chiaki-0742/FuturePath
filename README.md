# FuturePath

> 大学生未来规划系统。帮在校学生把「我是谁 → 我要去哪 → 我怎么去」想清楚，把模糊的规划变成可执行的步骤。

四年很长，但大多数人在大四才发现路选错了。学校只在毕业前才动手指导，网上的建议要么太泛、要么是别人的路。FuturePath 想填的就是这段空白：从入学到毕业，一直陪着走。

## Why This Project

「要趁早规划」这句话，每个人都听过；「具体第一步该迈哪里」，很少有人告诉你。我们把规划拆成四步：

- 先搞清楚自己适合什么（发展测评）
- 再确定要往哪走（我的未来规划）
- 把目标拆成按学期排列的任务
- 把走过的每一步记录下来

这四步是一条闭合的链条，缺任何一环都会断：

| 如果只做 | 结果 |
| --- | --- |
| 测评，不规划 | 测完就忘了 |
| 规划，不记录 | 计划空转，看不到进度 |
| 记录，不求助 | 攒了一堆材料，还是不知道下一步 |

## Core Modules

四个核心模块，目前都在开发中。

| 模块 | 解决什么 | 具体做什么 | 状态 |
| --- | --- | --- | --- |
| 发展测评 | 我是谁 | 测出兴趣方向、能力倾向、性格特点，转化成具体的专业与职业建议 | 计划中 |
| 我的未来规划 | 我要去哪 | 选定考研 / 就业 / 考公 / 留学 / 创业方向后，拆成按学期、按月份排列的任务 | 计划中 |
| 成长记录 | 我走到了哪 | 实习、比赛、项目、志愿活动随手记下，自动累积成成长档案 | 计划中 |
| AI 规划助手 | 我卡住了 | 基于个人资料和成长记录回答具体问题，不给放之四海皆准的废话 | 计划中 |

## Who It Is For

| 你是 | 能解决什么 |
| --- | --- |
| 大一 / 大二学生 | 还没定方向，想尽早搞清楚自己适合什么 |
| 大三学生 | 面临考研 / 就业的实际选择，需要有人帮着拆步骤 |
| 大四学生 | 想复盘四年做了什么，整理成简历材料 |
| 任何在校生 | 对自己的未来感到迷茫 |
