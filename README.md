FuturePath · 大学生未来规划系统
四年很长，别走到大四才发现路选错了。
FuturePath 是一个帮大学生把「我是谁 → 我要去哪 → 我怎么去」想清楚的规划工具。
你有没有过这些时刻
- 大二了，还不确定自己到底适合考研、就业还是出国
- 简历上想写点什么，发现自己好像什么都没做过
- 听过很多"要趁早规划"的建议，但具体该做什么，没人告诉你
- 定了目标，三天后忘光，学期末发现计划还停在笔记本第一页
这些不是"你不够努力"的问题，而是没有人帮你把方向变成具体的、可执行的步骤。
学校的就业指导中心通常只在毕业前才出手；网上搜到的建议要么太泛（"多实习、多学技能"），要么是别人的路，套不到自己身上。
FuturePath 想填的就是这段空白：从入学到毕业，一直陪着你。
它做什么
FuturePath 把「规划」这件事拆成四个能落地的模块：
1. 发展测评 —— 先搞清楚你是谁
通过一系列测评，帮你看清自己的兴趣方向、能力倾向、性格特点。
不是那种测完给你一个"你是艺术家型人格"就完事的娱乐测试，而是把结果转化成具体的专业方向和职业建议——你适合什么、不适合什么、为什么。
很多人的迷茫根源不是"不够努力"，是在往一个不适合自己的方向上使劲。
2. 我的未来规划 —— 把大目标拆成小步骤
选一个方向（考研 / 就业 / 考公 / 留学 / 创业……），系统帮你拆成按学期、按月份排列的具体任务。
比如你选了"考研"，它会告诉你：这个学期该做什么、什么时候开始准备数学、什么时候联系导师、什么时候报名。你只要跟着走，不用每天焦虑"我现在是不是落后了"。
3. 成长记录 —— 把每一步都变成证据
大学四年最容易出现的问题是：做了很多事，但说不出来。
实习、比赛、项目、志愿活动、读过的书——随手记下来，自动累积成一份属于你自己的成长档案。等到写简历、面试、申请学校的时候，不用搜肠刮肚回想"我大二干过什么"，直接翻记录就行。
这一模块的价值在于：让"我努力过"变成"我拿得出证据"。
4. AI 规划助手 —— 随时有人可问
规划路上总会有具体的问题：这个专业考研值得吗？我现在开始学编程来得及吗？这家公司值不值得去？
AI 助手基于你的个人资料和成长记录来回答，而不是给一些放之四海皆准的废话。它知道你是谁、你在哪一步、你想去哪，所以给的建议是针对你的。
为什么是这四个
它们不是随便凑的四个功能，而是一条完整的链条：
测评    →     规划     →     记录     →     求助
"我是谁"      "我要去哪"     "我走到了哪"    "我卡住了"
   ↓             ↓              ↓            ↓
 认识自己      确定方向        累积成果      随时答疑
缺任何一环都会断：
- 只测评不规划 → 测完就忘了
- 只规划不记录 → 计划空转，看不到进度
- 只记录不求助 → 攒了一堆材料，还是不知道下一步
FuturePath 想做的是一条闭合的路，而不是四个孤立的小工具。

目前完成的是整套系统的基础骨架 + 用户体系：
- 用户注册 / 登录
- 个人资料管理（姓名、专业、年级）

上面那四个核心功能模块，目前只做了入口，正在逐个开发中。
这是一个从零开始的项目，由三名在校学生开发。功能会一块一块加上来，欢迎关注进展。
适合谁用
- 大一、大二学生 —— 还没定方向，想尽早搞清楚自己适合什么
- 大三学生 —— 面临考研 / 就业的实际选择，需要有人帮着拆步骤
- 大四学生 —— 想复盘自己四年做了什么，整理成简历材料
- 对自己未来感到迷茫的任何在校生
如果你正在纠结"我这四年该怎么过"，这个工具就是为你做的。

一点说明
做这个项目的原因很简单：我们自己就是迷茫过来的大学生。
那些"要早早规划""要多尝试"的建议，我们听了太多，但从来没人告诉我们具体第一步该迈哪里。所以想做一个工具，把这件事变得不那么难。
如果你在用的时候觉得哪里不对、哪里缺了，欢迎来说。这是给我们自己做的，也是给所有和我们一样的人做的。
