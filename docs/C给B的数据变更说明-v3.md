### 2.3 ⚠️ 重要：「还没想好」为什么故意不给案例

「还没想好」不是"数据缺失"，而是**用户还没定方向的正常状态**。

如果硬给它塞案例，等于系统替用户做了选择，这跟产品定位不符。所以：

- 后端走到你的**第 3 层兜底**（方向匹配不到 → 给全表通用案例 + `relaxed=true`）
- 前端看到 `relaxed=true`，文案改成「**先看看大家的选择，再决定自己的路**」

**你的三层兜底设计在这里刚好用上了，不用改。** 我只是在文档里把这个语义写清楚了。
