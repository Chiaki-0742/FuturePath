## 一、这周的总体目标

一句话：**把 App 从"只能登录"变成"能告诉用户该往哪走"。**

| 不做（放到节后） | 做（本周完成） |
|---|---|
| ❌ 接入大模型 | ✅ 问卷题库 + 问卷页 |
| ❌ 正式上线部署 | ✅ 案例数据 + 案例页 |
| ❌ 复杂推荐算法 | ✅ 简单规则匹配 |
| | ✅ 全流程联调 |

**为什么不接大模型**：需要申请 API、充钱、调提示词，不确定性大。
**先把不花钱、能立刻见效的两层做完**，App 就有演示价值了。大模型节后加，是"升级"不是"返工"。

## 八、如果做不完怎么办

**优先保这三个**（做不完就砍其他）：

1. **问卷模块**（第一层，没它后面都做不了）
2. **案例展示**（第二层，产品的核心卖点）
3. **首页展示方向**

**可以砍的**：
- 案例的复杂筛选（只按方向筛就够了）
- 新手引导的动画效果
- 案例详情的花哨排版

**绝对不能砍的**：数据落库 + 接口联调。**功能丑没关系，跑不通就白做了。**
